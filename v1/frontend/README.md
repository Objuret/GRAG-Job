# Antigrav Interface

Vite/React workbench for graph-RAG. Local-only — the browser talks directly to Neo4j (`neo4j-driver`) and Anthropic (`@anthropic-ai/sdk`).

```bash
npm install
npm run dev    # http://127.0.0.1:5173/
```

Docs: [`../docs/frontend/`](../docs/README.md). Agents: [`../AGENTS.md`](../AGENTS.md).
