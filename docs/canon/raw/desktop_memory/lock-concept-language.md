When the user and I converge on a concept (a design, a formula, a mechanism),
state it once in plain words and then KEEP that phrasing. Do not restate it in
new jargon, new metaphors, or new parameterizations in later messages ("max" →
"dot product" → "pairwise multiply and sum" for the same step).

**Why:** each rename reads as if the implementation changed mid-conversation;
the user can't tell renamed-same from actually-different, so trust collapses
and they have to re-interrogate settled ground.

**How to apply:** after sign-off, refer to the mechanism by the same short name
every time. If the implementation genuinely must change, say explicitly "this
CHANGES what we agreed" and what moved. Related: [[heed-user-intent-not-correct-it]],
[[match-output-to-the-ask]].
