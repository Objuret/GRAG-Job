Never cut corners. Do the task completely and properly; do not take shortcuts, skip steps, stub things out, or present partial/degraded work as if it were finished.

**Why:** The user stated this emphatically as a permanent standing instruction.

**How to apply:** Implement the full solution, not the minimum that appears to work. If a proper solution is blocked or genuinely out of scope, stop and say so explicitly — do not silently substitute a lesser one. Report skipped or incomplete steps plainly rather than glossing over them. Related: [[no-silent-fallbacks]], [[docs-track-reality]].
