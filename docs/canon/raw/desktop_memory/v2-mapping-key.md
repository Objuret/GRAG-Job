**Mapping-key finalization (user-decided 2026-06-12), closing the items [[v2-graph-spine]] deferred to "the mapping-key decision":**

- **Attribute vs stays-in-raw discriminator = repetition ratio.** Probe measures distinct/total per scalar field across the fuse (descriptive stat next to maxlen). Shared values (channel names, state, type) → indexed attributes; per-record-unique free-form (title, link, description) → stay in raw behind references. No key entry, no per-dataset threshold tuning — the gap is a chasm.
- **The key's one new field: `kind` on directory declarations and on the source-name space**, drawn from the interpreter's universal enum. Starting set `person` / `org` / `product` (product covers named systems/tools — Bonnier). HERB: employee.json + customers_data.json = person, sources = product. The interpreter-flag → which-directory-to-fuzzy-search join is literal equality on kind.
- **Interpreter = one-shot flagger, NO tools, one-way pipeline.** Prompt in → flags out (kind + wanted-vs-excluded). Deterministic code runs the scoped distance lookup after; nothing returns to the model. One model call per query, fixed. Testable as a pure function. "Agentic-but-lean" lives a level up (anchored retrieval), never inside literal matching.
- **Enum is universal (language ontology, fixed contract); the ACTIVE subset is dataset-derived** = union of kinds the key declares ("what can be asked about in hard fields" is emergent at the join, never in the interpreter's context). Unlandable flags → no lookup, fall to semantic layer, logged loudly (that log = eval evidence for extending a key).
- **File-scoped values = File-node attributes.** Rule: attributes ride at the structural scope where the value sits. File-level hit boosts through containment — broader/weaker than a chunk hit; magnitude belongs to the open combinator math. NOTE: HERB's only instances (team[]/customers[]) turned out RAG-unsafe and are stripped (next bullet) — rule stands, vacuous for HERB, live for Bonnier.
- **Confirmed already-handled (don't reopen):** content choice, directory declarations, id-space assignment all settled in the 05-30 draft; named-transforms escape hatch vacuous for HERB. The key now lives at `v2/backend/v2/keys/Salesforce__HERB.yaml` (moved out of .work scratch 2026-06-12).
