THE MODEL OF THE EDGE, his words, 2026-09-18: "my thinking is that the "main weight" on a tag, is the topic one, and the others adjust that weight depending on the relevance of a facet to the query". Topic = cos(tag embedding, chunk-description embedding), harness embedder; it exists on every edge and is not touched. The four others — temporal, why, activity, concreteness, defined in section 2 of the record — describe that connection from four angles, query-independent, relative to it. They must never re-establish whether the tag is relevant; topic did that. The 09-17 build failed precisely by defining each facet as lost overall relevance (record, section 9b).

THE CONSTRUCTION TO TEST, topic's own: a model writes a short description of the chunk as seen through one facet, in the tagger's register (the tagger's description prompt is in git history at commit c301840; read it), describing, never judging, never a verdict, nothing invented; the facet value is cos(tag, that view) with the harness embedder. Two variants, both built and tested: per chunk (the chunk's temporal content as a whole, one text per chunk per facet) and per edge (the chunk's temporal content as it concerns this tag). Which one is the concept is decided by the isolation test, not by cost.

THE CHECK. The 13,044 counterfactuals on disk (`output/facet_neural/counterfactuals/herb-eval-volmax/`, plus `counterfactuals_repeat/`) are the falsification instrument, never a source of values: after the temporal neutralization for tag T on chunk C, T's temporal value must fall; T's topic and its other three facet values must hold; the other tags' temporal values on that same text must move less than T's; a view written twice must give nearly the same cosine (the writer's noise); the relation generated twice (the 24 repeat chunks) must agree. Each facet's cosine distribution is reported on its own — the same embedder is not the same scale; values are read by position within their own column and relative to topic, never raw across facets. If the targeted facet's drop is not larger than the writer's repeat noise, or the other facets fall with it, the construction is dead: say so, find out why, and go to the alternatives.
