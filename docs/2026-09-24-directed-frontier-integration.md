# Tag recruitment crossed with management routes

The earlier tag-frontier population found two fixed development leaders:
2,008 hits using all positive query-tag sponsors, and macro source-ID recall
0.5354352816384299 (1,934 hits) using first query-tag sponsors. The management-route
population independently showed that route direction and placement affect the
downstream ordering. This comparison joins those structural choices in the same
retrieval program.

The 39 programs retain the canonical reference and both unchanged tag parents,
then cross each parent with channel/product employee bindings, forward/reverse/
symmetric management direction, and replace/before/parallel walk placement.
`tag_frontier_gate` acts before edge-to-chunk aggregation. The resulting chunk
evidence then enters `directed_propagate` at the named position in the graph
walk. The route cannot read corpus bodies, gold, delivery costs or source text.
Sponsor aggregation here is maximum, with the parent's destination gate and
0.5 decay. The separate direction experiment contains mean/sum controls.

The additive engine preserves the earlier sealed engines. Its cache key includes
the numeric frontier gate and directed-route identity; gate changes cannot reuse
stale source values. Focused tests verify this and the whole gate-to-edge-to-chunk-
to-directed-transit ordering. The 39-program one-case smoke independently verifies
delivery accounting, and both unchanged tag parents reproduce full-order hashes
and deliveries exactly.

The full sealed plan is in
`output/research/2026-09-24-directed-frontier-programs/plan.json`.
The population was queued behind the running query-priority and tag-followup
experiments to avoid competing heavy workers. The commands are:

```powershell
.venv/Scripts/python.exe -B tools/facet_directed_frontier_lab.py batch --out output/research/2026-09-24-directed-frontier-programs
.venv/Scripts/python.exe -B tools/facet_directed_frontier_audit.py
.venv/Scripts/python.exe -B -m pytest test/tests/test_facet_directed_frontier.py -q
```

The full population completed: 95 cases, 39 programs, 3,705 independently
verified deliveries. All 190 unchanged tag-parent full orders, deliveries,
budgets and metrics reproduce the original population exactly. Evidence is in
`directed-frontier-audit.json` in the population folder.

The strongest combined rule has **2,015 hits**, macro recall
**0.5331311126104045**, using the 2,008-hit tag parent and a channel-bound management
route joined with the seed before the existing walk. Forward (`0004`), reverse
(`0007`) and symmetric (`0010`) directions tie on these aggregate metrics; direction
cannot be credited specifically for the improvement. The seven additional hits
come from case_091, increasing 0/12 to 7/12; 94 cases tie on hit count, with no
losses. This localized development-set gain is not a generalization result.
The strongest macro recall remains **0.5354352816384299**, with 1,934 hits.

These are source-ID retrieval measurements under the 72,000-character serving
budget, not RAGAS, held-out validation, or a per-case gold selector.
